# 2026-09-04 生产采集诊断修复

诊断证据：服务器 Bing 返回酒店/邮箱等不相关内容，原逻辑遇到非空结果便停止其他引擎；DDG网络不可达；最高检等网站列表不匹配通用 h2/h3 选择器；其余来源包括 DNS、404、521及拒绝连接。不能归因为没有相关新闻。

本次修复：搜索仅在获得符合主题和域名的HTTP链接后停止回退；命名来源按域名定向检索并校验结果，避免全网内容错标发布机构；全网来源按实际发布域名入库；部分查询失败明确计入部分失败；来源状态记录候选、相关、新增和查询有效比例，失败保留具体错误；最高检使用实测列表结构，并分离标题和日期；修复DDG目标链接查询参数解析。未放宽相关性过滤，未导入演示素材。

验证：8项故障回归、12项安全回归、流水线测试和接口冒烟通过。本机实时最高检列表解析30条。测试不能代替ECS网络验收。
