# MUHUB 项目收录与生命周期（试运营）

## 1. MUHUB 项目收录定位

MUHUB 是所有项目的公众信息平台，不是 GitHub 项目库。  
GitHub / GitCC 是重要信息源和技术项目信号，但不是项目成立或收录的必要条件。

## 2. 项目收录标准

项目可被 MUHUB 收录，需要满足：

- 有明确项目名称；
- 有至少一个公开信息来源；
- 公开来源中可识别项目的模式、定位、团队、产品、服务、技术、内容、场景、用户、运营动态等任一类信息。

公开来源包括但不限于：

- GitHub / GitCC / 公开代码仓库
- 官方网站
- 新闻报道
- 媒体文章
- 微信公众号文章
- 产品平台页
- 社交媒体账号
- 产业园 / 孵化器 / 协会项目页
- 活动页面
- 项目方主动提交资料

## 3. GitHub 的角色

- GitHub 是加分项，不是必要条件。
- GitHub 用于判断技术活跃度、代码质量、版本迭代和开发者生态。
- 没有 GitHub 的项目，只要有公开信息来源和可识别项目内容，也可以进入 MUHUB。

## 4. 非技术项目收录说明

MUHUB 支持文化、教育、消费、文旅、社区、企业服务、产业服务、公益、内容媒体等非技术项目收录。

## 5. 项目退出主信息流展示标准

自收录之日起半年内，若同时满足以下条件：

- 通过公开搜索未发现新增消息；
- 且项目未被认领；

则进入观察库，不再默认出现在主信息流中。

观察库不是删除：

- 项目仍保留；
- 可搜索、可后台查看；
- 后续发现新动态或被认领后，可恢复主信息流展示。

## 6. 当前试运营流程

公开信息源 -> 项目发现队列 -> 导入项目草稿 -> 项目编辑页补来源 -> AI 结构化分析 -> 人工确认 -> 发布。

## 7. 后续系统方向

- Source Material / ProjectSource 全局复用
- 项目认领
- 官方媒体与运营信息
- 观察库
- 定期公开信息搜索与动态更新
