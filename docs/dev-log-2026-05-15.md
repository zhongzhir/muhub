### 1.2 子域名路由 `middleware.ts`

在 Next.js 中间件加入 Host 检测逻辑，将 `training.muhub.cn` 的请求 rewrite 到 `/training` 路由：

```typescript
const host = req.headers.get("host") ?? "";
if (host.startsWith("training.")) {
  const url = req.nextUrl.clone();
  if (!url.pathname.startsWith("/training")) {
    url.pathname = url.pathname === "/" ? "/training" : `/training${url.pathname}`;
    return NextResponse.rewrite(url);
  }
  return NextResponse.next();
}
```

同步更新 `config.matcher`，添加 catch-all 路径以覆盖子域名流量：

```typescript
"/((?!_next/static|_next/image|favicon.ico).*)",
```

## 六、技术备忘

**文件截断问题根因**：Claude 的 Edit 工具在对大文件进行局部编辑时，偶发截断文件末尾内容的 bug。规避方式：

1. 对中文内容较多的大文件，优先使用 Python 写入（`open(path, 'w', encoding='utf-8')`），而非 Edit 工具
2. 每次写入/编辑后立即用 `python3 -c "raw=open(path,'rb').read(); raw.decode('utf-8')"` 验证完整性
3. `git stash pop` 前先用 `git stash show -p` 确认内容，避免覆盖已修复的文件
